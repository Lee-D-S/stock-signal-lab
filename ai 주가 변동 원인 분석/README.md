# 주가 변동 원인 분석 정리

## 폴더 구조

- `00_기업별분석`: 기업별 보고서와 원본 분석 산출물 (events.jsonl 포함)
- `01_기획`: 프로젝트 목적, 실행 흐름, 해석 기준
- `02_기준`: 판단 기준과 실행 규칙
- `03_원천데이터`: 이벤트 집계, 분포 요약, PER/EPS 현재 스냅샷
- `04_패턴분석`: 패턴 후보, 국면별 분석, PER/EPS 밸류에이션 요약
- `05_가설검토`: 가설별 이벤트 리뷰와 요약
- `06_백테스트`: 대리/실전 백테스트와 보조 결과
- `07_전략신호`: 전략 조건 초안, 관심종목 후보 및 확정 시그널
- `08_관찰기록`: 확정 후보 관찰 로그, 외국인 순매수/정배열/팩터 스코어 관찰 기록, 성과 요약
- `09_조건스냅샷`: 날짜별 조건 스냅샷 (가설 검토·백테스트·이벤트 전체 보관)
- `10_일일요약`: 일별 운영 요약 리포트

## 08_관찰기록 주요 파일

- `관찰_로그.csv/md` — 확정 전략 시그널의 일별 관찰 기록 및 D+1/5/10/20 수익률 추적
- `외국인순매수_관찰_로그.csv/md` — 외국인 연속 순매수 후보 관찰 기록 및 D+ 수익률 추적
- `단기정배열_관찰_로그.csv/md` — 단기 정배열(MA5>MA20>MA60>MA120) 종목 관찰 기록 및 D+ 수익률 추적
- `장기정배열_관찰_로그.csv/md` — 장기 정배열(MA60>MA120>MA240) 종목 관찰 기록 및 D+ 수익률 추적
- `스코어_관찰_로그.csv/md` — 팩터 스코어 임계값 이상 종목 관찰 기록 및 D+ 수익률 추적
- `관찰_성과_요약.csv/md` — 전체 관찰 성과 집계 및 통계

## 회사별 분석
