# Daily/Morning 자동 실행 흐름

이 문서는 GitHub Actions 워크플로 `.github/workflows/daily_auto.yml` 기준으로 `morning`과 `daily`가 실행될 때 어떤 일이 일어나는지 정리한다.

## 공통 실행 조건

- 워크플로 이름: `일별 자동 루틴`
- 자동 실행:
  - `morning`: 평일 07:05 KST, 08:35 KST
  - `daily`: 평일 15:55 KST
- 수동 실행:
  - GitHub Actions `workflow_dispatch`
  - `job`: `morning`, `daily`, `both`, `telegram-test`
  - `date`: 비우면 KIS 최신 거래일 또는 각 스크립트의 기본 기준일 사용
- 휴장일 처리:
  - 자동 schedule 실행은 `holidays.Korea()` 기준으로 한국 날짜가 주말/공휴일이면 실제 작업을 건너뛴다.
  - 수동 실행은 공휴일이어도 실행된다.
- 실행 환경:
  - Python 3.12
  - `requirements.txt` 설치
  - GitHub Secrets에서 KIS, DART, Gemini, Telegram 값을 주입한다.

## Morning: 오전 DART 공시 확인

### 실행 시각

- 자동: 평일 07:05 KST, 08:35 KST
- 수동: `job=morning` 또는 `job=both`

### 실행 스크립트

```bash
python -u scripts/auto_morning_dart_check.py
```

### 처리 흐름

1. 한국 거래일 여부를 확인한다.
   - 자동 실행이고 휴장일이면 의존성 설치 이후 작업, 텔레그램 알림을 모두 건너뛴다.
   - 수동 실행이면 거래일 여부와 무관하게 진행한다.
2. 여러 관찰/후보 소스에서 오전 DART 조회 대상을 만든다.
   - 로컬 보유 종목
   - 공통 관찰 로그: `08_관찰기록/00_공통/관찰_로그(이상).csv`
   - 외국인 순매수/순매도 관찰 로그: `08_관찰기록/01_외국인수급/`
   - 신규 조건 관찰 로그: `08_관찰기록/05_신규조건/`
   - 확정 후보, 외국인 수급 후보, 거래대금 유니버스, 보고서 필요 종목
3. DART 기업코드와 관찰 종목을 매칭한다.
4. 마지막 성공 morning 조회 이후 새로 확인 가능한 DART 공시를 조회한다.
   - 상태 파일이 없으면 직전 거래일 15:30 KST 이후를 초기 기준으로 삼는다.
   - `rcept_no` 기준으로 이미 알린 공시는 신규 알림에서 제외한다.
5. 신규 공시가 있으면 최대 3건까지 상세 내용을 확인하고 간단한 해석을 만든다.
   - 텔레그램에는 조회 대상 수, 대상 출처별 건수, corp_code 누락 수, 신규 공시별 대상 출처/편입 사유를 함께 보낸다.
   - IR, 결산실적공시예고, 주주총회, 배당/기준일 계열 공시는 원문에서 미래 날짜를 추출해 이벤트 캘린더에 저장한다.
6. 관찰 로그에 공시 확인 결과를 반영한다.
7. Markdown 관찰 로그에 오전 공시 확인 섹션을 추가한다.
8. 텔레그램으로 결과를 보낸다.
   - 신규 공시가 있으면 종목별 공시명과 해석을 보낸다.
   - 신규 공시가 없으면 "신규 공시 없음" 메시지를 보낸다.
   - 이미 공시된 오늘~3거래일 이내 핵심 미래 이벤트를 함께 보낸다.
   - 공시 상세가 길면 텔레그램 제한을 피하도록 여러 메시지로 나눠 보낸다.
   - 텔레그램 전송 실패는 job 실패로 드러나 GitHub Actions 실패 알림 대상이 된다.
9. 변경된 관찰 로그를 커밋하고 `main`에 push한다.
10. GitHub Actions의 성공/실패 알림도 별도로 텔레그램에 보낸다.

### 주요 산출물

- `08_관찰기록/00_공통/관찰_로그(이상).csv`
- `08_관찰기록/00_공통/관찰_로그.csv`
- `08_관찰기록/00_공통/관찰_로그.md`
- `08_관찰기록/07_공시이벤트/공시_이벤트_캘린더.csv`
- `08_관찰기록/07_공시이벤트/공시_이벤트_캘린더.md`
- `08_관찰기록/07_공시이벤트/morning_dart_state.json`

### 원격 반영

`morning` job은 마지막에 다음 경로를 git에 추가한다.

```bash
git add "ai 주가 변동 원인 분석/"
```

변경 사항이 있으면 GitHub Actions bot이 커밋하고 `main`에 push한다.

커밋 메시지 형식:

```text
auto: 오전 공시 확인 업데이트 YYYY-MM-DD
```

따라서 `morning` 실행 후 원격에 반영된 공시 확인 결과를 로컬에서 보려면 다음을 실행한다.

```bash
rtk git pull --rebase origin main
```
