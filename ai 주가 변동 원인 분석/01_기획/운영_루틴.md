- 전일 지수 마감, 외국인/기관 순매수 동향 간단 확인 (장 흐름 파악용)

## 매 거래일 — 장 중 (09:00~15:30)

관찰 로그와 일일 요약에 기록된 종목만 확인. 전체 거래대금 유니버스를 매일 수동으로 볼 필요 없음.

**매수 후보 (H01 유형)**
- 시가 확인: 전일 종가 대비 갭 상승이 3% 이상이면 추격 보류
- 장초반 급락(-2% 이상)이면 당일 진입 보류

**반등 감시 후보 (H02/H03 유형)**

**추격매수 회피 후보 (H06/H04 유형)**

## 매 거래일 — 장 마감 후 (15:30~15:40)

- GitHub Actions `daily`가 장 마감 후 후보 탐지, 수급 재조회, 관찰 로그, D+ 추적, 성과 요약, 일일 요약을 자동 갱신한다.
- 직접 확인할 1순위는 `10_일일요약/일일_운영_요약_latest.md`, `07_전략신호/01_관심종목/관심종목_시그널_후보_확정.md`, `08_관찰기록/00_공통/관찰_로그.md`다.
- 필요할 때만 캔들 패턴 보조 점검: `rtk python -u scripts/run_candlestick_observation.py --mode daily`
  - 캔들 점검은 일일 자동 파이프라인에 포함하지 않는다.
  - OHLCV는 `data/ohlcv_cache`를 우선 사용하며, daily 기본 조회 범위는 60일이다.
  - 캐시를 무시하고 다시 조회해야 할 때만 `--force-refresh`를 붙인다.
  - 핵심 daily 자동화에 넣지 않고, 의심 구간이나 보조 확인이 필요할 때만 수동으로 돌린다.

## 전략 세트 업데이트 기준

아래 조건 중 하나 이상일 때만 전략 세트 변경 검토.

- 기존 가설이 20건 이상에서 hit rate 40% 미만 지속
- 시장 국면이 명확히 바뀜 (예: 금리 사이클 전환, 테마 교체)
- 새 분기 데이터에서 기존과 다른 패턴이 통계적으로 반복 확인됨

단순히 최근 몇 건이 실패했다고 가설을 바꾸지 않는다. 샘플이 적을수록 노이즈다.
