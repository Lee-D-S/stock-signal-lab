# 통합 특성 기반 상승·하락 조건 발견 계획

## 1. 목표

과거 시점에 실제로 알 수 있었던 가격·거래량, 기술 지표, 투자자 수급,
밸류에이션, 재무, 시장·업종 수치만 결합하여 다음 두 방식으로 조건을 찾는다.

1. 조건 선행 탐색: `외국인 3일 연속 순매도 + PER 구간 + 거래대금 증가` 같은
   특성 조합을 만들고 이후 수익률을 측정한다.
2. 결과 역추적 탐색: 실제 상승·하락 사례의 공통 특성을 찾고 명시적 조건으로
   변환한 뒤, 사용하지 않은 기간에서 다시 검증한다.

뉴스, 인물의 발언·방문, 소문, 개별 사건의 의미를 예측하거나 해석하지 않는다.
외부 사건이 시장에 영향을 주더라도 그 결과로 나타난 가격, 거래대금, 수급,
변동성 변화만 측정한다.

발견된 조건은 바로 매매에 사용하지 않는다. 학습, 검증, 최종 테스트,
실시간 모의 관찰을 통과한 조건만 전략 검토 대상으로 승격한다.

최종 목표는 특정 종목에서만 잘 맞는 조건이 아니라 여러 종목, 업종, 연도,
시장 국면에서 평균적으로 반복되는 통계적 우위를 찾는 것이다.

## 2. 완료 기준

- 가격·기술·수급·재무·시장 특성과 미래 수익률이 결합된 시점 기준 데이터셋
- 상승과 하락, D+1/D+3/D+5/D+10/D+20별 독립 탐색
- 단일 조건과 2개 조건 조합 자동 탐색
- 결과 역추적 후보의 일반 조건 변환 및 재검증
- 종목별 절대값과 날짜별 횡단면 순위·백분위 조건을 함께 탐색
- 학습·검증·최종 테스트 기간 완전 분리
- 표본 수, 종목 편중, 연도·시장 국면별 안정성 보고
- 알파 조건과 포지션 크기·노출 한도 등 위험관리 규칙 분리
- 통과 조건의 기존 `09_조건스냅샷` 및 관찰 파이프라인 연결
- 관찰 조건이 주문 로직으로 자동 승격되지 않는 안전장치

## 3. 현재 기반과 부족한 부분

### 재사용할 기반

- OHLCV 기술 특성 수집기
- 외국인·기관·개인 수급 로더
- DART 재무 특성 로더
- 단일 임계값 조건 탐색기
- 기존 이벤트 탐색기는 별도 연구 도구로 유지하되 기본 퀀트 전략 입력에서는 제외
- 조건 스냅샷, 일일 신호 수집, 사후 재검토 파이프라인

### 보완 사항

- 모든 특성군을 동일한 `날짜 × 종목` 행에 결합하는 표준 데이터셋 부재
- 과거 시점 기준 PER/PBR 등 밸류에이션 이력 부족
- 과거 종목 유니버스·업종 이력 부족에 따른 생존 편향
- 시장 국면과 업종 상대 특성 부재
- 다중 가설 검정과 종목·업종 편중 검사 부족

## 4. 전략 범위

### 기본 전략에 포함

- 가격, 수익률, 추세, 변동성
- 거래량, 거래대금, 유동성
- 외국인·기관·개인 수급
- 밸류에이션과 재무 품질
- 시장·업종 상대강도와 수치 기반 시장 국면
- 거래비용, 포지션 크기, 종목·업종 집중도

### 기본 전략에서 제외

- 뉴스 본문과 감성 분석
- 유명인 방문·발언이나 사회적 화제
- 소문과 비정형 외부 사건
- 사건별 수동 의미 해석
- 특정 기업 이름을 직접 조건으로 사용하는 규칙

외부 사건의 원인을 입력하지는 않지만 이미 가격과 수급에 반영된 반응은 일반 수치
특성으로 처리한다. 따라서 시스템은 사건을 예측하지 않고 관측 가능한 시장 반응에 대응한다.

## 5. 핵심 원칙

### 시점 무결성

- 날짜 `T`의 특성은 `T` 시점까지 공개된 정보만 사용한다.
- 종가 기반 신호의 기본 진입가는 `T+1` 시가다.
- 재무 데이터는 회계 기준일이 아니라 실제 공개일 이후부터 사용한다.
- 실제 공개일이 없으면 보수적인 `available_from`을 사용하고 표시한다.
- 미래 수익률과 상승·하락 여부는 목표값으로만 사용한다.

### 탐색과 검증 분리

- 임계값, 특성 선택, 조합 선택은 학습 기간에서만 수행한다.
- 검증 기간은 후보 유지·탈락 판단에만 사용한다.
- 최종 테스트는 조건 정의를 고정한 뒤 한 번만 실행한다.
- 테스트 결과를 보고 조건을 수정하면 그 기간은 테스트로 재사용하지 않는다.

### 단순한 조건 우선

- 단일 조건부터 시작하고 2개 조건 조합까지만 기본 탐색한다.
- 3개 이상 조합은 검증된 2개 조건을 확장할 때만 허용한다.
- 복잡한 모델은 상호작용 후보를 찾는 용도로만 사용하고 명시적 규칙으로 환원한다.

### 종목 독립성과 횡단면 비교

- `특정 종목이면 매수` 같은 종목 식별자 기반 규칙은 만들지 않는다.
- 절대 임계값과 함께 매 거래일 전체 유니버스 내 순위·백분위를 계산한다.
- 예: 모멘텀 상위 10%, 거래대금 증가율 상위 20%, 수급 강도 상위 15%.
- 종목마다 단위와 분포가 다른 특성은 횡단면 순위 또는 종목 자체 과거 대비 표준점수로 비교한다.
- 조건은 최소 종목 수와 종목별 기여도 제한을 통과해야 한다.

### 알파와 위험관리 분리

- 알파 모델은 매수·회피·하락 후보의 상대 순위를 결정한다.
- 위험 모델은 포지션 크기, 총 투자 비중, 종목·업종 한도, 손실 제한을 결정한다.
- 시장 국면은 사건 해석이 아니라 지수 추세·변동성·시장 폭으로 전체 노출을 조절한다.
- 높은 예측 점수가 곧 큰 투자 비중이 되지 않도록 위험 예산을 별도로 적용한다.

## 6. 데이터 계약

### 기본 행

```text
기준일 T × 종목 코드
```

필수 키와 메타데이터:

- `date`, `ticker`, `name`, `market`, `sector`
- `listing_age_days`
- `feature_available_at`
- 데이터 원천, 결측 사유, 품질 플래그

### 목표값

```text
entry = T+1 시가
exit = T+D 종가
return = exit / entry - 1
```

보유 기간은 D+1, D+3, D+5, D+10, D+20을 각각 독립 평가한다.

- 상승: `return > 0`
- 강한 상승: `return >= +1%`, `return >= +3%`
- 하락: `return < 0`
- 강한 하락: `return <= -1%`, `return <= -3%`

## 7. 탐색 특성 범위

### 가격·기술

- 1/3/5/10/20/60일 수익률
- 이동평균 괴리율·기울기·정배열·역배열
- 신고가·신저가 거리, 갭, 연속 상승·하락 일수
- 변동성, ATR, 볼린저 밴드 위치와 폭
- RSI, MACD, Stochastic, OBV, 모멘텀
- 거래량·거래대금 이동평균 대비 비율과 유동성 구간
- 날짜별 횡단면 순위·백분위
- 종목 자체 과거 분포 대비 z-score와 백분위

### 투자자 수급

외국인·기관·개인별:

- 당일 순매수 수량·금액
- 2/3/5/10/20일 누적 순매수
- 거래량·거래대금 대비 순매수 비율
- 연속 순매수·순매도 일수
- 수급 방향 전환
- 외국인·기관 동시 수급과 개인 반대 수급
- 가격과 수급의 다이버전스

### 밸류에이션·재무

- PER, PBR, PSR와 업종 대비 상대값
- ROE, ROA, 영업이익률, 부채비율
- 매출·영업이익·순이익 성장률
- 최근 실적 개선·악화 방향
- NTM PER 및 PEG 대용치

과거 시점 자료가 없으면 현재 값을 과거 날짜에 복사하지 않는다.

### 시장·업종

- KOSPI/KOSDAQ 1/5/20일 수익률과 변동성
- 상승·하락 종목 비율과 시장 거래대금
- 상승장·하락장·횡보장, 위험 선호·회피 국면
- 업종 수익률과 종목의 시장·업종 대비 상대강도
- 종목의 유니버스 내 종합 상대 순위

### 사용하지 않는 특성

- 뉴스·공시 텍스트 감성
- 인물, 방문, 발언, 소문 같은 사건 분류
- 종목명, 기업명 또는 특정 회사 여부
- 미래에 확정된 사건 결과나 사후 작성된 원인 분석

## 8. 기간과 종목 범위

초기 기간:

- 학습: 2020-01-01 ~ 2022-12-31
- 검증: 2023-01-01 ~ 2024-12-31
- 최종 테스트: 2025-01-01 ~ 모든 원천이 완전히 적재된 마지막 날짜

초기 종목 범위:

- 수집 가능한 KOSPI/KOSDAQ 유동성 상위 종목
- 최소 240거래일 가격 이력
- 거래정지·관리종목·상장 직후 종목 별도 표시
- 현재 유니버스를 과거에 적용하면 `survivorship_bias` 경고 표시

2차 단계에서 날짜별 과거 유니버스, 상장폐지 종목, 당시 업종 소속을 복원한다.
생존 편향 해결 전 결과는 연구 후보까지만 허용한다.

## 9. 후보 생성 절차

### 1단계: 단일 특성

- 연속형 특성은 학습 데이터 분위수와 금융적으로 의미 있는 임계값으로 구간화한다.
- 날짜별 횡단면 상·하위 백분위와 종목 자체 과거 대비 백분위를 함께 만든다.
- 범주형 특성은 값별로 평가한다.
- 표본 수, 평균·중앙값 수익률, 상승 비율, 기준 대비 개선폭을 계산한다.
- 상승 후보와 하락 후보를 별도로 저장한다.

### 2단계: 결과 역추적

- 강한 상승군과 일반군, 강한 하락군과 일반군의 특성 분포를 비교한다.
- 효과 크기, 반복 빈도, 연도별 방향 일관성이 큰 특성을 선별한다.
- 선별 특성을 명시적 임계값 조건으로 변환한다.
- 변환된 조건을 학습 전체에 다시 적용한 후 일반 후보와 동일하게 검증한다.

### 3단계: 2개 조건 조합

단일 조건 중 학습 기준을 통과한 후보만 조합한다.

- 가격/기술 + 수급
- 가격/기술 + 재무/밸류에이션
- 수급 + 재무/밸류에이션
- 종목 특성 + 시장/업종

같은 정보를 다른 형태로 표현한 조건끼리는 조합하지 않는다.

### 4단계: 제한적 모델 탐색

얕은 결정 트리나 규제 로지스틱 회귀로 놓친 상호작용을 찾는다.
모델 자체는 조건으로 채택하지 않고 2~3개의 설명 가능한 규칙으로 변환될 때만
후보 생성기로 되돌린다.

## 10. 후보 평가 기준

### 최소 표본

- 학습 100건 이상
- 검증 50건 이상
- 최소 20개 종목
- 한 종목의 표본 기여도 10% 이하

표본 기준을 충족하지 못하는 조건은 성과가 높아도 탐색 결과에서 탈락시킨다.

### 성과 지표

- 평균·중앙값 수익률
- 양수·음수 비율
- 전체 및 동일 국면 기준 집단 대비 개선폭
- 상위·하위 10% 수익률
- Profit Factor와 최대 낙폭
- 최대 유리·불리 움직임
- 거래 비용 적용 후 성과

### 안정성 검사

- 연도별
- KOSPI/KOSDAQ별
- 업종별
- 상승·하락·횡보장별
- 고·저변동성별
- 시가총액·유동성 구간별
- 조건에서 제외한 종목에 대한 전이 성과

전체 평균이 좋아도 특정 연도, 종목, 업종에만 의존하면 탈락시킨다.

### 우연한 발견 통제

- 학습 결과 FDR 보정
- 기준 집단 대비 부트스트랩 신뢰구간
- 필요 시 날짜 단위 순열 검정
- 전체 탐색 조건 수와 단계별 탈락 수 기록

### 범용성 통과 기준

- 특정 종목을 제거해도 성과 방향이 유지된다.
- 특정 업종 하나를 제거해도 성과가 붕괴하지 않는다.
- 학습에 없던 종목군에서도 기준 대비 개선폭이 유지된다.
- 절대 임계값 조건과 횡단면 순위 조건을 비교하여 더 안정적인 표현을 선택한다.
- 시장 국면별 성과 차이는 허용하되 손실 국면에서는 위험 모델로 노출을 축소할 수 있어야 한다.

## 11. 후보 생명주기

```text
generated
  -> train_pass
  -> validation_pass
  -> test_pass
  -> research_candidate
  -> shadow_observation
  -> strategy_review
  -> approved | rejected | frozen
```

- 자동 생성 조건은 주문에 사용하지 않는다.
- 테스트 통과 후에도 수동 검토를 거친다.
- 실시간 관찰은 신호 30건과 3개월을 모두 충족할 때까지 유지한다.
- 실제 주문 전략 편입은 별도 승인 단계에서만 가능하다.

## 13. 단계별 구현

### Phase 0. 데이터 계약과 누수 방지

- 표준 행 스키마와 원천별 `available_at` 정의
- 진입가·목표값과 학습·검증·테스트 기간 고정
- 재무 발표 전 값, 미래 가격, 당일 종가 체결 누수 테스트

완료 조건: 시점 무결성 테스트 전체 통과.

### Phase 1. 가격·기술 데이터셋

- 기존 OHLCV 수집기 재사용
- 가격·추세·변동성·거래량·기술 특성 생성
- D+1~D+20 목표값 생성
- 임의 종목 수동 계산과 중복·결측 검사

완료 조건: 동일 입력에서 데이터셋과 결과가 재현됨.

### Phase 2. 투자자 수급

- 외국인·기관·개인 수급 결합
- 누적·연속·비율·다이버전스 특성 생성
- 원천 누락과 실제 0값 구분
- 휴장일 경계와 원천 자료 대조

완료 조건: 수급 특성 품질 보고서 생성.

### Phase 3. 1차 조건 탐색

- 가격·기술·수급의 단일 조건 탐색
- 절대 임계값과 횡단면 순위 조건 비교
- 상승·하락 결과 역추적
- 2개 조건 조합
- 학습/검증 평가, 편중·연도 안정성 검사

완료 조건: 모든 후보 정의와 탈락 사유가 재현 가능하게 저장됨.

### Phase 4. 시장·업종

- 지수, 시장 폭, 거래대금, 변동성 특성
- 시장 국면과 업종 상대강도
- 국면 분류 기준이 학습 기간에서만 결정되는지 검사

완료 조건: 모든 행에 시장 국면 또는 명시적 결측 사유가 존재.

### Phase 5. 재무·밸류에이션

- DART 재무와 실제 공개일 결합
- 과거 PER/PBR 원천 확보
- 업종 상대 밸류에이션
- 현재 값을 과거로 복사한 행이 없는지 검사

완료 조건: 최소 3개 연도의 시점 기준 재무 특성 생성.

### Phase 6. 위험 모델

- 변동성 기반 포지션 크기
- 총 투자 비중과 종목·업종 집중 한도
- 시장 국면별 전체 노출 상한
- 거래비용과 유동성 한도
- 알파 점수와 위험 예산의 독립 적용

완료 조건: 동일 알파 신호에서도 위험도에 따라 비중이 제한되고 최대 노출 규칙이 지켜짐.

### Phase 7. 최종 테스트와 관찰 등록

- 조건 정의 파일을 잠근 뒤 테스트 기간 일괄 평가
- 통과 후보만 연구 후보로 등록
- 기존 조건 스냅샷과 신호 수집 파이프라인 연결
- 조건 정의 해시와 자동 주문 차단 검사

완료 조건: 테스트 보고서와 관찰용 조건 정의 생성.

### Phase 8. 운영 자동화

- 일일 특성 갱신과 연구 후보 신호 수집
- D+1~D+20 성과 사후 채움
- 월간 유지·동결·탈락 보고서
- 재실행 중복, 미완료 성과, 데이터 지연 검사

완료 조건: 신호 생성부터 사후 성과 갱신까지 반복 실행 가능.

## 14. 첫 구현 범위

첫 구현은 범위를 다음으로 제한한다.

- 가격·기술 + 외국인·기관·개인 수급
- D+1과 D+5
- 상승과 하락 별도 탐색
- 단일 조건과 2개 조건 조합
- 절대 임계값과 횡단면 순위 비교
- 학습/검증 분리
- 연도별·종목 편중 검사
- 기본 변동성 기반 포지션 한도
- Markdown/CSV/JSON 보고서

이 범위로 전체 검증 구조를 먼저 완성한 뒤 시장·업종, 재무·밸류에이션,
위험 모델을 순서대로 확장한다. 뉴스·사건 분석은 기본 전략에 추가하지 않는다.

## 16. 구현 우선순위

1. 시점 데이터 계약과 누수 테스트
2. 가격·기술 데이터셋과 목표값
3. 투자자 수급 결합
4. 단일 조건, 횡단면 순위 및 결과 역추적
5. 2개 조건 조합과 검증
6. 시장·업종 상대강도와 수치 기반 국면
7. 재무·밸류에이션
8. 독립 위험 모델
9. 최종 테스트와 실시간 모의 관찰

재무 데이터 준비를 기다리며 전체 개발을 멈추지 않는다. 먼저 신뢰 가능한 가격·수급
범위로 검증 구조를 완성하고 데이터 원천이 준비되는 순서대로 수치 특성군을 추가한다.

## 17. 주요 위험과 대응

- 과최적화: 조건 수 제한, 기간 분리, 통계 보정, 국면별 안정성 검사
- 시점 데이터 부족: 현재 값 대체 금지, 원천별 품질 플래그
- 생존 편향: 결과 경고, 과거 유니버스 복원 전 전략 승격 금지
- 종목·업종 편중: 종목 기여도 상한과 업종별 성과 분해
- 데이터 지연: 결측과 0 구분, 원천별 최신 적재일과 공통 완료일 기록
- 외부 사건 충격: 원인 예측 대신 가격·수급 반응 측정, 변동성 기반 비중 축소
- 범용성 착각: 미관측 종목군과 종목·업종 제거 검증을 별도 수행
